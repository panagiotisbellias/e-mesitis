# ADR0001 — Choose Open Source License

## Status
Accepted

## Context
We are preparing the initial open-source / internal pre-release of the project (v1.0.0).  
A license must be included to define legal usage, distribution, and contribution terms.

## Decision
We will use the **Apache License 2.0** as it is permissive, widely adopted, and suitable for public collaboration.

## Consequences
- The repository now includes a `LICENSE` file in the root.
- Future contributions must include this license header where applicable.
- This decision will be referenced in future ADRs and documentation.
