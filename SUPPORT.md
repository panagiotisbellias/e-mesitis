# Support

Thank you for using **e-mesitis** 🙌

This document explains how to get help, report issues, and contribute feedback.

---

## 📌 Before Asking for Help

Please take a moment to:

* Check the **README.md** for setup and usage instructions
* Search existing **GitHub Issues** to see if your problem is already reported or solved
* Make sure you are using the **latest version** of the code

Doing this helps keep support efficient and focused.

---

## 🐞 Reporting Bugs / Issues

If you encounter a bug or unexpected behavior, please open a **GitHub Issue**:

👉 [https://github.com/panagiotisbellias/e-mesitis/issues](https://github.com/panagiotisbellias/e-mesitis/issues)

When creating an issue, include:

* A clear and descriptive title
* Steps to reproduce the problem
* Expected vs actual behavior
* Relevant logs or error messages
* Your environment (OS, Java version, Ant version)

Issues without enough information may be delayed or closed.

---

## 💡 Feature Requests

Feature requests are welcome!

Please open a GitHub Issue and label it as:

* `enhancement` or `feature-request`

Describe:

* The problem you are trying to solve
* Why this feature would be useful
* Any ideas for implementation (optional)

---

## ❓ Questions & Discussions

For general questions, usage help, or design discussions:

* Use **GitHub Issues** with the label `question`
* Clearly state what you are trying to achieve

(At the moment, there is no dedicated forum or mailing list.)

---

## 🔐 Security Issues

If you discover a **security vulnerability**, please **do not open a public issue**.

Instead:

* Contact the maintainer privately (via GitHub profile or email)
* Provide a clear description and steps to reproduce

Responsible disclosure is appreciated.

---

## 🤝 Contributing

Contributions are welcome!

* Fork the repository
* Create a feature or fix branch
* Open a Pull Request with a clear description

Please ensure:

* Code compiles successfully
* Existing functionality is not broken
* Changes are well described

---

## ⏱ Response Expectations

This is a community-driven / personal project.

* Responses may take some time
* Support is provided on a **best-effort basis**

Thank you for your patience and for using **e-mesitis** ❤️
