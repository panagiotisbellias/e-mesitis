# 🗺️ Roadmap

This roadmap outlines the planned direction of the project and highlights areas where contributors can get involved.

> ⚠️ Note: Priorities may shift based on feedback and available time.

---

## 🚀 Current Focus

### Core Stability & Testing
- [ ] Increase unit test coverage across all modules
- [ ] Add integration tests (including DB interactions)
- [ ] Fix flaky or unstable tests
- [ ] Improve test documentation

### Code Quality
- [ ] Resolve static analysis issues (PMD, linting)
- [ ] Refactor legacy / complex code paths
- [ ] Standardize logging and error handling

## 📝 Versioning Strategy

This project follows **semantic versioning**:
- `MAJOR` – Breaking changes
- `MINOR` – New features (backwards-compatible)
- `PATCH` – Bug fixes
