# 🧭 Code of Conduct (Internal)

This **Code of Conduct** outlines expectations for all internal contributors working on **E Mesitis**.  
Its goal is to maintain a respectful, collaborative, and productive environment.

---

## 1. Expected Behavior

All contributors are expected to:

- Treat colleagues with **respect**, **professionalism**, and **fairness**.
- Communicate clearly and constructively.
- Provide supportive, actionable feedback.
- Collaborate openly and avoid creating unnecessary conflict.
- Protect confidential project information.
- Follow agreed‑upon workflows, processes, and security practices.

---

## 2. Unacceptable Behavior

The following behaviors are not tolerated:

- Harassment, discrimination, or personal attacks.
- Dismissive, hostile, or unprofessional communication.
- Sharing internal or sensitive information without authorization.
- Knowingly breaking build pipelines, security rules, or review processes.
- Introducing malicious, harmful, or negligent code or configurations.

---

## 3. Scope

This Code applies to all project-related interactions, including:

- GitHub / GitLab repositories  
- Internal chat channels (Teams, email, etc.)  
- Meetings and discussions  
- Documentation and code reviews  

---

## 4. Reporting Issues

If you observe or experience a violation:

- Report privately to the **project lead** or **team supervisor**.
- Reports are handled confidentially and respectfully.
- Retaliation against reporters is strictly prohibited.

---

## 5. Enforcement

Violations may result in:

- Verbal or written warning  
- Temporary removal from project work  
- Escalation to management  
- Access restriction if necessary  

---

## 6. Acknowledgment

By contributing to **E Mesitis**, you acknowledge that you have read and will follow this Code of Conduct.
